我想第一次問 AI 什麼是 Neovim 時，非常大的可能性會得到 Lazy 的字眼吧，事實上你可能得到兩個不同概念

*   lazy.vim 是插件管理器
*   LazyVim 是一個使用 [lazy.nvim](https://www.lazyvim.org/) 的 Neovim 配置

簡單來說 lazy.vim 可以讓你輕鬆安裝任何你可以找到別人開發好的，使用起來順手的插件；而 LazyVim 是一堆插件的發行版。當然如果選擇了直接從發行版入手的話，也覺得並無不可，我的確一開始也是從發行版開始玩的。只是就像玩 neovim 的初心一樣意思，從 VS Code 轉換一個你可以大多數功能跟快捷鍵都用不到的編輯器😆是不是直接在 VS Code 裝 vim 模式還比較快[1]
