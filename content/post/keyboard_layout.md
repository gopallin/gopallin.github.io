如果大家仔細看這張照片的紅框處，可以發現少了個 micro USB 連接器！全都是因為我測試時頻繁的插拔不小心掰斷的。剛好斷的那顆又是我預計要寫入的主控板，隨之而來的後果就是我需要把所有鍵位都設成鏡像。

(線上鍵位排列：
https://config.qmk.fm/#/bluebell/swoop/LAYOUT_split_3x5_3)

秉持著精簡的原則，我設計了以下兩層，分別是

1. LAYER 0: 平常慣用的字母、符號。*註1 
2. LAYER 1: 右手上下左右設定成與 vim 排列用的一致；左手則是拿 enter、tab、del 與 esc

> 註1. 幸好我中打都是使用嘸蝦米，不用考慮注音的 41 鍵

另外 LAYER 0 左下角有個 MO 1 是指按著可以進到 LAYER 1 的意思，放開就又回到 LAYER 0；一開始我是設定成 TG 去 toggle 切換，但發現這樣常常讓我不知道目前在哪一層造成困惑，所幸就改成了 MO。

以下附上常用的幾個切換鍵說明：

| 鍵碼 | 全名 | 行為 | 具體使用情境 |
| :--- | :--- | :--- | :--- |
| **`MO(n)`** | Momentary | 按住時啟用第 n 層，放開即回到原層 | **最常用（如 Shift）**：按住左手拇指鍵切換至「數字層」，右手快速輸入數字 `1` `2` `3` 後放開拇指，立即恢復主層輸入文字。 |
| **`TG(n)`** | Toggle | 按一下開、再按一下關，切換後會維持 | **長時間停留某層**：打遊戲時切換至「遊戲層」（將 WASD 對齊或停用 Win 鍵）；或是臨時把鍵盤變成單手「滑鼠/方向鍵操控層」。 |
| **`TO(n)`** | To | 啟用第 n 層並關閉其他所有層（清空高層堆疊） | **深層跳回/緊急回家鍵**：當從主層切進「數字層」，再切進「Fn 鍵層」時，按一下 `TO(0)` 可一次清空所有疊加層，安全回到最乾淨的 Layer 0。 |
| **`TT(n)`** | Tap-Toggle | 按住 = 暫時啟用 (`MO`)；連續點按 5 次 = 鎖定切換 (`TG`) | **一鍵兩用**：輸入單一符號時按住即可；若需要寫數十行 SQL 或輸入整排數字，連點 5 次鎖定在數字層，輸完再點一下解鎖。 |
| **`LT(n, kc)`** | Layer Tap | 按住 = 啟用第 n 層；輕點 = 送出 `kc` 這個鍵 | **36 鍵省鍵位神器**：將拇指鍵設為 `LT(1, KC_SPC)`，輕點是「空格 Space」，按住不放則瞬間變成「Layer 1 切換鍵」。 |

> **🤖 AI 補充說明：為什麼接頭斷了，鍵位就要變鏡像？**
> 
> 在分離式鍵盤中，通常會有一邊直接插線連著電腦（主控）。而很多鍵盤的預設規則是：**「有插上線連著電腦的那一半，就是左手」**。
> 
> 當原本預計要插線的左手接頭斷掉時，只能把線改插到右手的板子上。這時候，鍵盤的「大腦」會依照預設規則，以為現在連著電腦的這塊右手板是左手，因此按下按鍵時，送出的訊號全都會對應成左手的設定。
> 
> 為了不修改複雜的底層程式碼，最簡單的解決方法就是在設定介面中，把左右兩邊的按鍵配置直接**「鏡像對調」**。這樣一來，雖然板子的左右被大腦誤認了，但因為按鍵設定也跟著反過來，負負得正，打字時就能輸出正確的字母囉！
