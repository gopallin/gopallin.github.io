當我有了做鍵盤的想法後，一直苦於沒能找到 Mac 巧控板的替代品，巧控板帶來直覺操控感真的無可取代，但用了分離式鍵盤後我的雙手又離巧控板太遠不好操作。

這時候我找到這隻小貓 shortcat 其功能能讓我單單使用鍵盤就能快速定位到畫面上的各個連結或按鈕

曾經一位 senior 跟我說過：

懶惰是好的工程師必備條件之一

可以一勞永逸的事實在是沒有不做的道理。乾脆把召喚 shortcat 的三個鍵 (shift, cmd, space) 做成一個複合鍵好了！而下張圖的紅框處就是我的複合鍵位置。步驟如下：

  1. 先在 QMK 把鍵位序列好，而我們要的複合鍵就隨便用一個鍵代替，如：KC_F3

  1. 按下 download 的 icon，下載 .json

#include QMK_KEYBOARD_H
#if __has_include("keymap.h")
#    include "keymap.h"
#endif

/* THIS FILE WAS GENERATED!
 *
 * This file was generated by qmk json2c. You may or may not want to
 * edit it directly.
 */

enum custom_keycodes {
    SC_SPACE = SAFE_RANGE,
};

const uint16_t PROGMEM keymaps[][MATRIX_ROWS][MATRIX_COLS] = {
    [0] = LAYOUT_split_3x5_3(KC_P, KC_O, KC_I, KC_U, KC_Y, KC_T, KC_R, KC_E, KC_W, KC_Q, KC_SCLN, KC_L, KC_K, KC_J, KC_H, KC_G, KC_F, KC_D, KC_S, KC_A, KC_SLSH, KC_DOT, KC_COMM, KC_M, KC_N, KC_B, KC_V, KC_C, KC_X, KC_Z, MO(1), KC_SPC, KC_LGUI, KC_LALT, KC_LCTL, KC_LSFT),
    [1] = LAYOUT_split_3x5_3(KC_0, KC_9, KC_8, KC_7, KC_6, KC_5, KC_4, KC_3, KC_2, KC_1, KC_MINS, KC_RGHT, KC_UP, KC_DOWN, KC_LEFT, SC_SPACE, KC_ENT, KC_TAB, KC_NO, KC_GRV, KC_EQL, KC_RBRC, KC_LBRC, KC_BSLS, KC_QUOT, KC_LGUI, KC_BSPC, KC_ESC, KC_NO, KC_NO, KC_TRNS, KC_SPC, KC_LGUI, KC_LALT, KC_LCTL, KC_LSFT)
};

bool process_record_user(uint16_t keycode, keyrecord_t *record) {
    switch (keycode) {
        case SC_SPACE:
            if (record->event.pressed) {
                register_code(KC_LSFT);
                register_code(KC_LGUI);
                tap_code(KC_SPC);
                unregister_code(KC_LGUI);
                unregister_code(KC_LSFT);
            }
            return false;
    }
    return true;
}

#    include OTHER_KEYMAP_C
#endif // OTHER_KEYMAP_C
