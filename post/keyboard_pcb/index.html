我會選這塊板子有幾個重要原因：

  1. 不是直列鍵盤，對剛接觸分離式鍵盤的我來說上手應該不會太困難
  2. 因為我中打使用嘸蝦米，可以不用考慮數字鍵，這板子剛好鍵數適中，尺寸討喜
  3. 不用 3D 列印外殼
  4. 最重要的是 youtube 上有教學，直接照著做就可以了😤

步驟

1. 準備檔案

上 swoop github 直接下載好 zip 檔案 (swoop-mx-2.2-pcb.zip)

2. 上傳到 JLCPCB 並進行打樣

上 JLCPCB 報價頁面 並參照下方 gif 上的流程

注意： zip 上的檔案是單片的，數量一定要填雙數（因為是分離式鍵盤，需要左右各一片）

3. 收到 PCB 🎉
